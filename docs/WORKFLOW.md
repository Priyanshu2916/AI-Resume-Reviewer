# AI Resume Reviewer - System Workflow

## User Workflow

User
↓
Login / Signup
↓
Upload Resume
↓
Extract Resume Text
↓
Select Target Job Role
↓
Enter Job Description
↓
AI Analysis
↓
Resume + Job Description Matching
↓
Generate Results
↓
Dashboard
↓
Improvement Suggestions

## Main Modules

### 1. Authentication
- User Registration
- User Login
- JWT Authentication

### 2. Resume Management
- Upload PDF/DOCX Resume
- File Validation
- Resume Text Extraction
- Store Resume Information

### 3. AI Resume Analysis
- Overall Resume Score
- ATS Score
- Strengths
- Weaknesses
- Skills
- Missing Skills
- Missing Keywords
- Improvement Suggestions

### 4. Job Matching
- Select Target Job Role
- Enter Job Description
- Compare Resume with Job Description
- Calculate Match Percentage
- Identify Matching Skills
- Identify Missing Skills

### 5. Dashboard
- Display Resume Score
- Display ATS Score
- Display Skills
- Display Missing Skills
- Display Suggestions
- Display Previous Reviews

### 6. Review History
- Save Previous Reviews
- View Previous Analyses
- Track Resume Improvement
